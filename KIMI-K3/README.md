# AURA — Apple-Style E-commerce Prototype

A premium, immersive storefront concept inspired by Apple's design language.
Dark cinematic hero with an interactive 3D product, scroll-driven storytelling,
glassmorphism product grid, and a sleek sticky navbar.

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Framer Motion (scroll & entrance animations)
- React Three Fiber + drei (3D product rendering)
